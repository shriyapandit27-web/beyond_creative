Visual Storyboard – Microlearning Simulation
Shot Visual Text Interaction
Shot 1
Opening Hook 		Card UI fades in over a soft gradient background. Progress bar starts empty. “Learn this in under 2 minutes” Card slides up slightly. Start button pulses once.
Shot 2
Scenario Setup 		Customer avatar or chat bubble appears. Text types in. Customer: “This product is too expensive.” Typing animation with soft notification sound.
Shot 3
Decision Point 		Two large buttons slide up from the bottom. Progress bar at 33%. What should you do?
• Explain features immediately
• Acknowledge concern & ask a question 		Hover / tap animation. User selects an option.
Shot 4A
Correct Feedback 		Selected button glows green. Checkmark appears. “Good choice! Empathy builds trust.” Progress bar animates from 33% to 66%.
Shot 4B
Incorrect Feedback 		Button shakes gently with muted red outline. “Jumping to features may feel dismissive.” Try-again prompt appears.
Shot 5
Outcome 		Customer avatar relaxes. Background slightly brightens. “Customer feels heard and stays engaged.” Smooth text fade-in. Subtle UI glow.
Shot 6
Completion 		Progress bar fills to 100%. Soft confetti animation. 🎉 Microlearning Complete
“You handled the objection effectively.” 		CTA buttons appear: Replay / Next Scenario / Tip Card.
